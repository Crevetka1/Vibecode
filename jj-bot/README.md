# JJ бот · NAS100

Telegram-бот, который в нью-йоркскую сессию в реальном времени выдаёт сигналы по NAS100
и отвечает на каждый сигнал результатом (тейк / стоп).

## Что делает

- **Сессия:** 9:30–12:30 по Нью-Йорку — это 17:30–20:30 МСК зимой (летом 16:30–19:30, когда в США летнее время).
- **Справедливая цена:**
  - красных новостей USD на ForexFactory сегодня нет → цена открытия Нью-Йорка (9:30);
  - красная новость вышла → цена в минуту выхода новости (если их несколько — последней вышедшей).
    Новости до открытия (например CPI в 8:30) тоже учитываются.
- **Сигнал:** направление, сетап, вход, тейк, стоп, справедливая цена, время NY/МСК.
- **Результат:** ответом (reply) на сообщение с сигналом — ✅ тейк, ❌ стоп или ⏹ закрытие в конце сессии, в пунктах и $.
- За ±5 минут вокруг красной новости новые сделки не открываются; одна позиция одновременно, максимум 3 за сессию.
- В 9:25 NY — статус дня, в пятницу 16:00 NY — итоги недели.

## Сетапы (5-минутные свечи)

1. **Снятие ликвидности → возврат к справедливой.** Свеча обновляет максимум последних 6 свечей,
   но закрывается обратно под ним (медвежья), при этом цена минимум на 30 п выше справедливой → SHORT. Зеркально — LONG.
2. **Пробой и ретест справедливой.** Цена была под справедливой, пробила её вверх, вернулась
   к уровню (±8 п) и закрылась бычьей свечой выше → LONG. Зеркально — SHORT.

Если стоп и тейк задеты в одной минуте, засчитывается стоп. Все параметры — в `.env`.
Логика сетапов лежит в `jjbot/strategy.py` (функция `detect_setup`), её легко заменить на свою.

## Команды

`/start` — подписаться и показать статус · `/status` · `/news` — красные новости до конца недели ·
`/stats` — итоги текущей недели · `/stop` — отписаться

## Запуск

```bash
cp .env.example .env        # вписать TELEGRAM_TOKEN от @BotFather
pip install -r requirements.txt
python -m jjbot
```

Или в Docker:

```bash
docker build -t jjbot .
docker run -d --restart=always --env-file .env -v jjbot-data:/data jjbot
```

Бота нужно держать запущенным постоянно (VPS / сервер), чтобы он работал в сессию.

## Данные

- Котировки: Yahoo Finance, минутные свечи. По умолчанию `NQ=F` (фьючерс Nasdaq-100) — у него есть
  цена до открытия, нужная для новостей в 8:30. Уровни фьючерса могут отличаться от CFD NAS100
  у брокера на несколько десятков пунктов, но расстояния стоп/тейк те же.
  Можно поставить `SYMBOL=^NDX` (сам индекс, данные только с 9:30).
- Новости: официальный JSON-фид календаря ForexFactory (`nfs.faireconomy.media`), обновляется раз в час.
